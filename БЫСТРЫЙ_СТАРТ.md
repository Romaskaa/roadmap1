## ?? Troubleshooting

### Проблема: Тесты не запускаются
**Решение:**
```
1. Tools ? NuGet Package Manager ? Manage NuGet Packages
2. Убедиться, что MSTest установлен
3. Перестроить решение: Build ? Rebuild Solution
```

### Проблема: "The type 'TestClassAttribute' is not found"
**Решение:**
```
1. Install-Package MSTest.TestFramework -Project newproj.Tests
2. Add reference: newproj ? newproj.Tests
3. Перестроить решение
```

### Проблема: Файлы тестов не видны
**Решение:**
```
1. View ? Solution Explorer (Ctrl+Alt+L)
2. Убедиться, что видна папка newproj.Tests
3. Если нет, перезагрузить проект
```
